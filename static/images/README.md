# Mengganti gambar website

Ganti file gambar di folder ini dengan gambar baru, lalu pertahankan nama file yang sama agar tidak perlu mengubah kode website.

| Nama file | Digunakan untuk |
| --- | --- |
| `wedding-merapi.jpg` | Foto hero dan portofolio wedding |
| `prewedding-golden-hour.jpg` | Foto pre-wedding |
| `portrait-graduation.jpg` | Foto portrait hero |
| `proofing-dsc02266.jpg` | Foto 1 di galeri Portal Proofing |
| `proofing-dsc02366.jpg` | Foto 2 di galeri Portal Proofing |
| `proofing-dsc02011.jpg` | Foto 3 di galeri Portal Proofing |
| `proofing-dsc02059.jpg` | Foto 4 di galeri Portal Proofing |
| `proofing-dsc02693.jpg` | Foto 5 di galeri Portal Proofing |
| `proofing-dsc02674.jpg` | Foto 6 di galeri Portal Proofing |
| `photographer-cutout.png` | Foto fotografer transparan pada kartu tim |
| `camera-sony.jpg` | Foto kamera |
| `godox-lighting.jpg` | Foto lighting |
| `portfolio-wedding.jpg` | Karya wedding |
| `portfolio-prewedding.jpg` | Karya pre-wedding |
| `portfolio-product.jpg` | Karya produk/kopi |
| `portfolio-portrait.jpg` | Karya wisuda/portrait |

Kartu tim menampilkan `photographer-cutout.png` dengan kepala keluar dari bingkai dan badan berhenti di tepi atas panel nama.

Gunakan gambar berukuran file yang sudah dioptimalkan untuk web. Jika nama file atau formatnya diubah, perbarui referensinya di `static/js/data.js` atau template terkait.

Foto Koleksi Karya memakai gambar yang diberikan langsung oleh pengguna.
