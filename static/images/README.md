# Image library

Images are grouped by where they are used. Keep filenames descriptive and update
the matching template or `static/js/data.js` reference when replacing an asset.

| Folder | Contents |
| --- | --- |
| `hero/` | Graduation and pre-wedding images on the home slide |
| `portfolio/` | Wedding, product, and graduation portfolio cards |
| `proofing/` | RAW proofing gallery images |
| `shared/` | Images used across multiple sections |
| `team/` | Photographer portrait |
| `gear/` | Camera images |

Proofing source photos are delivered as optimized WebP where applicable. The
original camera filenames remain visible in the proofing gallery.
